# 🤖 Telegram Bot для учета заказов

Автоматический бот для приема заказов из Telegram и записи в Google Таблицы с использованием Claude AI.

## 🌟 Возможности

- ✅ Автоматическое распознавание заказов с помощью AI
- ✅ Запись в Google Таблицы
- ✅ Автоматическое добавление даты/времени и статуса
- ✅ Работает 24/7 на хостинге

## 📋 Структура заказа

```
*Заказ*
• Продавец: Наргиз
• Товар: Подарочный бокс
• Номер: +996 502 995 421
• Адрес: ул.Тирек 36
• Выкуп: 1590
• Предоплата: 500
• Доставка: 200
```

## 🚀 Установка

### Переменные окружения (Environment Variables):

- `TELEGRAM_TOKEN` - токен вашего Telegram бота
- `CLAUDE_API_KEY` - API ключ Claude
- `GOOGLE_SHEET_ID` - ID Google Таблицы
- `GOOGLE_CREDENTIALS` - JSON с учетными данными Google Service Account

|---|---|---|---|---|---|---|---|---|
| 02.01.2026 14:35 | Наргиз | Подарочный бокс | +996... | ул.Тирек 36 | 1590 | 500 | 200 | Заказ принят |

## 🛠️ Команды бота

- `/start` - начать работу с ботом
- `/help` - помощь по использованию

## 📝 Использование

1. Отправьте боту сообщение с заказом
2. Бот автоматически обработает и запишет в таблицу
3. Получите подтверждение
